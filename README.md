# sky-squad — 함께 하는 비행기 슈팅

최대 4명이 각자 안드로이드 폰으로 함께 하는 협동 비행기 슈팅 웹게임입니다.
앱 스토어 없이 Chrome의 **홈 화면에 추가**로 설치합니다.

- 게임 주소: https://hwmill.github.io/sky-squad/
- 상세 설계: [SPEC.md](SPEC.md) (1차) · [SPEC-v2.md](SPEC-v2.md) (2차: 캐릭터·상점·스테이지 5)
- 현재 상태: **2차 완성** — 귀여운 캐릭터, 스테이지 1~5와 엔딩, 코인·상점, 혼자·2~4인 같이 하기

## 등장인물
- **뭉게 비행단** (나와 친구들): 1P 솜솜(하늘색·고글) · 2P 딸콩(분홍·딸기 모자) · 3P 완두(연두·새싹) · 4P 레몽(노랑·레몬 핀)
- **심술 과자단** (적): 젤리콩 · 심술 마카롱 · 사탕벌 · 쿠키 탱크 · 도넛 포대
- 배 가운데의 작은 분홍 점이 **실제로 맞는 곳**이에요. 그림에 살짝 닿는 건 괜찮아요.
- 모든 캐릭터를 한눈에 보려면 주소 뒤에 `?preview=chars`

## 스테이지 1~5
| 스테이지 | 하늘 | 보스 | 보스 공략 |
|---|---|---|---|
| 1 | 맑은 하늘 | 푸딩 대장 | 좌우로 출렁이며 부채꼴 탄. 아래를 따라다니며 쏘기 |
| 2 | 노을 구름 | 문어 사탕왕 | 다리 8개 끝에서 회오리 탄. 다리 사이 틈으로 |
| 3 | 바다 위 | 와플 거북선 | 등의 **포대 4개를 먼저** 부숴야 몸통에 맞아요 |
| 4 | 눈 내리는 산 | 번개 솜사탕 | **빨간 기둥이 보이면 옆으로!** 1초 뒤 번개가 쳐요 |
| 5 | 밤하늘 과자성 | 케이크 대마왕 | 3단 케이크. 한 단씩 무너질 때마다 더 화내요 |

- 스테이지가 오를수록 적이 조금씩 단단하고(체력 +20%) 탄이 빨라져요(+8%).
- **총알이 셀수록 적도 강해져요.** 총알 3단계까지는 그대로, 8단계(풀파워)면 적 체력 +40%·쏘는 횟수 +25%·탄 속도 +10%. 같이 할 때는 살아 있는 사람들의 평균 단계로 정해요.
- 스테이지 5 보스를 이기면 **엔딩**. 처음 화면에 **최고 점수**와 **최고 도달 스테이지**가 남아요.

## 코인과 상점
- 적을 물리치면 코인이 떨어져요(소형 1, 중형 5). 가까이 가면 끌려와요. **4초** 뒤에는 사라져요.
- 스테이지를 깨면 **보스 40 + 클리어 80**, 목숨을 하나도 안 잃었으면 **노미스 +50**. 한 스테이지에 보통 150~250개 모여요.
- 스테이지를 깰 때마다 **상점**이 열려요. 상품을 누르고 아래 **구매**를 한 번 더 누르면 사요. 실수로 샀으면 **되돌리기**.

| 상품 | 효과 | 가격 |
|---|---|---|
| 총알 파워업 | 총알 단계 +1 (최대 8단계) | 150 |
| 빠른 연사 | 발사 속도 +15% (3번까지) | 120 → 200 → 300 |
| 날쌘 날개 | 이동 속도 +10% (2번까지) | 100 → 180 |
| 폭탄 | 폭탄 +1 (최대 5개) | 80 |
| 생명 | 목숨 +1 (최대 5개, 상점마다 1개) | 300 |
| 보호막 | 다음 스테이지에서 한 번 맞아도 괜찮아요 | 150 |
| 큰 자석 | 코인 끌어오는 거리 2배 | 100 |

- 코인은 **이번 판에서만** 써요. 새 게임은 0부터, 이어하기는 코인을 그대로 두고 점수만 0부터.
- 같이 할 때: 코인은 **먼저 닿은 사람**이 가져가고, 보스·클리어 보너스는 **각자** 받아요. 상점은 **45초**, 모두 **준비 완료**를 누르면 바로 다음 스테이지로.

## 친구 맺기
1. 타이틀의 **👥 친구** → 닉네임(1~8자, 한글·영문·숫자)을 정합니다. 실명·전화번호는 받지 않아요.
2. **친구 초대 링크 보내기**로 카톡에 링크를 보냅니다.
3. 받은 사람이 링크를 **Chrome으로** 열고 닉네임을 정하면 서로 친구 목록에 뜹니다. (초록 점 = 접속 중)
4. 예전에 보낸 링크를 못 쓰게 하려면 **초대 링크 새로 만들기**.

## 폰에 설치하기
1. 폰의 **Chrome**으로 위 게임 주소를 엽니다. (카카오톡 안에서 열면 설치가 안 될 수 있어요)
2. 오른쪽 위 **⋮ 메뉴 → 홈 화면에 추가** (또는 "앱 설치")를 누릅니다.
3. 홈 화면의 sky-squad 아이콘으로 실행하면 주소창 없이 전체 화면으로 열립니다.
4. 한 번 열어 두면 **인터넷이 없어도(비행기 모드) 혼자 하기**가 됩니다.

## 같이 하기 (2~4명)
1. 타이틀의 **같이 하기** → 대기실이 열리고 내가 1P(방장)가 됩니다.
2. 접속 중인 친구 옆 **초대**를 누르면 친구 폰에 "같이 하자!" 알림이 뜹니다.
3. 친구가 **같이 하기**를 누르면 2P·3P·4P 자리에 들어옵니다. (1P 솜솜, 2P 딸콩, 3P 완두, 4P 레몽)
4. 방장이 **시작**. 점수는 각자 따로 셉니다. 사람이 많을수록 적이 단단해집니다.
- 게스트 연결이 끊겨도 **15초** 안에 다시 연결되면 같은 자리에서 이어서 해요.
- 방장이 앱을 내리거나 연결이 끊기면 모두 멈추고 **30초** 기다려요. 그 안에 돌아오지 않으면 게임이 끝나요.
- 앱을 새 버전으로 바꾸면 화면 위에 "새 버전이 있어요 [새로고침]"이 떠요.

## 조작
| 동작 | 방법 |
|---|---|
| 이동 | 화면 아무 곳이나 손가락으로 드래그 (손가락이 움직인 만큼 비행기가 움직여요) |
| 발사 | 자동 |
| 폭탄 | 오른쪽 아래 **B** 버튼 — 적 탄 전부 제거, 2초 무적 |
| 아이템 | **P** 총알 강화(최대 8단계) · **B** 폭탄 +1 · **1UP** 목숨 +1 |

목숨이 0이 되면 10초 안에 **이어하기**를 누르면 그 자리부터 계속합니다(점수는 0부터).
앱을 내리면 자동으로 일시정지됩니다.

## 폴더
| 폴더 | 내용 |
|---|---|
| `web/` | 화면 (GitHub Pages로 공개). `js/game/` 게임 계산·그리기, `js/ui/` 메뉴 화면 |

## PC에서 확인하기
```
cd web
python -m http.server 8080
```
- 브라우저에서 http://localhost:8080 — PC에서는 방향키/WASD 이동, 스페이스 = 폭탄
- `?debug=1` FPS 표시 · `?debug=1&boss=1` 보스 직전부터 시작
- 2차 확인용: `&stage=4` 4번째 스테이지부터 · `&power=8` 총알 8단계로 · `&coins=500` 코인 500개로 (예: `?debug=1&stage=3&boss=1&power=8`)
- `?preview=chars` 캐릭터 미리보기

테스트:
```
node --test tests/*.test.js
```

## 서버 (server/, Cloudflare Worker + Durable Objects)
```
cd server
npm install          # 처음 한 번
npx wrangler dev     # 로컬 서버 http://localhost:8787 (화면은 localhost:8080에서 자동으로 이 주소 사용)
npm test             # API 테스트
```
- Windows에서 실행이 바로 꺼지면 최신 **Microsoft Visual C++ 재배포 패키지(x64)**를 설치하세요.
- 배포: **자동** (아래 "서버 자동 배포"). 처음 한 번만 수동으로 `npx wrangler login` → `npx wrangler deploy` 했고, 나온 주소를 `web/js/config.js`의 `PROD_API_BASE`에 적어 두었습니다.
- 배포 확인: https://sky-squad-api.terry96.workers.dev/ 를 열면 `{"ok":true,...,"version":숫자}`. 서버 코드를 바꿀 때 `server/src/index.js`의 `SERVER_VERSION`을 올리면 반영 여부를 바로 알 수 있습니다.
- 서버에는 비밀값이 없습니다. 사용자 토큰은 해시로만 저장합니다.

## 서버 자동 배포 (Cloudflare Workers Builds, 처음 한 번 설정)
`main` 브랜치에 푸시하면 `server/` 폴더가 바뀐 경우에만 Cloudflare가 알아서 테스트하고 배포합니다.

1. Cloudflare 대시보드 → **Workers & Pages** → **sky-squad-api** → **Settings** → **Builds** → **Connect**
2. GitHub 연결(처음이면 Cloudflare GitHub 앱 설치 → 저장소 `hwmill/sky-squad` 선택)
3. 설정값
   | 항목 | 값 |
   |---|---|
   | Git branch | `main` |
   | Root directory | `server` |
   | Build command | `npm test` (테스트가 실패하면 배포하지 않음) |
   | Deploy command | `npx wrangler deploy` (기본값) |
   | Build watch paths (include) | `server/*` |
   | Enable Preview Builds | 끄기 |
4. 저장 후 `server/` 코드를 푸시하면 **Deployments**에 빌드가 보입니다. 무료 플랜은 한 달 3,000분, 한 번에 1개씩.
- Worker 이름(`sky-squad-api`)은 `server/wrangler.jsonc`의 `name`과 같아야 합니다. 다르면 빌드가 실패합니다.

## 화면 배포
- `main` 브랜치에 푸시하면 GitHub Actions(`.github/workflows/pages.yml`)가 `web/` 폴더를 Pages로 배포합니다.
- `web/` 파일을 바꿀 때는 `web/sw.js`의 `CACHE_VERSION`을 올려야 폰에 새 버전이 들어갑니다. (앱을 한 번 더 껐다 켜면 반영)

## 문제 해결
| 증상 | 해결 |
|---|---|
| "오늘 온라인 사용량을 다 썼어요" | 무료 한도는 매일 오전 9시(한국)에 초기화돼요. 혼자 하기는 계속 돼요 |
| "서버에 연결할 수 없어요" | 인터넷 연결 확인. 계속되면 오전 9시 이후에 다시 해 보세요 |
| 친구 초대 링크가 카톡에서 안 열림 | "Chrome으로 열기" 또는 ⋮ → 다른 브라우저로 열기 |
| 새 버전이 안 보임 | 앱을 완전히 껐다 켜거나 위의 [새로고침]을 누르세요 |
