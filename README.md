# sky-squad — 함께 하는 비행기 슈팅

최대 4명이 각자 안드로이드 폰으로 함께 하는 협동 비행기 슈팅 웹게임입니다.
앱 스토어 없이 Chrome의 **홈 화면에 추가**로 설치합니다.

- 게임 주소: https://hwmill.github.io/sky-squad/
- 상세 설계: [SPEC.md](SPEC.md)
- 현재 상태: **2단계(친구 등록)** 완성. 같이 하기는 3단계에서 만듭니다.

## 친구 맺기
1. 타이틀의 **👥 친구** → 닉네임(1~8자, 한글·영문·숫자)을 정합니다. 실명·전화번호는 받지 않아요.
2. **친구 초대 링크 보내기**로 카톡에 링크를 보냅니다.
3. 받은 사람이 링크를 **Chrome으로** 열고 닉네임을 정하면 서로 친구 목록에 뜹니다. (초록 점 = 접속 중)
4. 예전에 보낸 링크를 못 쓰게 하려면 **초대 링크 새로 만들기**.

## 폰에 설치하기
1. 폰의 **Chrome**으로 위 게임 주소를 엽니다. (카카오톡 안에서 열면 설치가 안 될 수 있어요)
2. 오른쪽 위 **⋮ 메뉴 → 홈 화면에 추가** (또는 "앱 설치")를 누릅니다.
3. 홈 화면의 sky-squad 아이콘으로 실행하면 주소창 없이 전체 화면으로 열립니다.
4. 한 번 열어 두면 **인터넷이 없어도(비행기 모드) 혼자 하기**가 됩니다.

## 조작
| 동작 | 방법 |
|---|---|
| 이동 | 화면 아무 곳이나 손가락으로 드래그 (손가락이 움직인 만큼 비행기가 움직여요) |
| 발사 | 자동 |
| 폭탄 | 오른쪽 아래 **B** 버튼 — 적 탄 전부 제거, 2초 무적 |
| 아이템 | **P** 총알 강화(최대 4단계) · **B** 폭탄 +1 · **1UP** 목숨 +1 |

목숨이 0이 되면 10초 안에 **이어하기**를 누르면 그 자리부터 계속합니다(점수는 0부터).
앱을 내리면 자동으로 일시정지됩니다.

## 폴더
| 폴더 | 내용 |
|---|---|
| `web/` | 화면 (GitHub Pages로 공개). `js/game/` 게임 계산·그리기, `js/ui/` 메뉴 화면 |
| `tests/` | 게임 규칙 테스트 |
| `tools/` | 앱 아이콘 생성 스크립트 |
| `server/` | Cloudflare Worker (2단계부터) |

## PC에서 확인하기
```
cd web
python -m http.server 8080
```
- 브라우저에서 http://localhost:8080 — PC에서는 방향키/WASD 이동, 스페이스 = 폭탄
- `?debug=1` FPS 표시 · `?debug=1&boss=1` 보스 직전부터 시작

테스트:
```
node --test tests/*.test.js
```

## 서버 (server/, Cloudflare Worker + Durable Objects)
```
cd server
npm install          # 처음 한 번
npx wrangler dev     # 로컬 서버 http://localhost:8787 (화면은 localhost:8080에서 자동으로 이 주소 사용)
npm test             # API 테스트
```
- Windows에서 실행이 바로 꺼지면 최신 **Microsoft Visual C++ 재배포 패키지(x64)**를 설치하세요.
- 배포: `npx wrangler login`(처음 한 번) → `npx wrangler deploy`. 나온 주소를 `web/js/config.js`의 `PROD_API_BASE`에 적고 푸시합니다.
- 서버에는 비밀값이 없습니다. 사용자 토큰은 해시로만 저장합니다.

## 배포
- `main` 브랜치에 푸시하면 GitHub Actions(`.github/workflows/pages.yml`)가 `web/` 폴더를 Pages로 배포합니다.
- `web/` 파일을 바꿀 때는 `web/sw.js`의 `CACHE_VERSION`을 올려야 폰에 새 버전이 들어갑니다. (앱을 한 번 더 껐다 켜면 반영)

## 지키는 것
- 개인정보는 받지 않습니다(닉네임만). 채팅, 결제, 광고, AI 기능 없음.
- 그림은 코드(Canvas 도형)로, 소리는 WebAudio 합성으로 직접 만듭니다.
